# OV13855 分辨率与视场实测（2026-09-22）

## 结论
当前 /dev/video11、NV12、15 fps 请求条件下，7 档分辨率均成功采集，实测画面覆盖范围一致，未发现明显裁剪。16:9 输出保留整个 4224×3136 画幅，通过横纵不同倍率缩放实现，相对于原始画幅横向拉宽约 31.99%。640×480、2560×1920 相对原始比例约横向压缩 1.01%。这不等同于测得镜头绝对视场角，未测角度值。

## 方法和限制
相机不动，逐档通过板端 OpenCV/GStreamer 直接采集 NV12→GRAY8，每档读取约 3 秒后保存末帧；没有 ROS、控制节点或主动图像裁剪。最后回到2560×1440并重复采集以检查场景漂移。每帧实际尺寸与请求一致，所有模式驱动 crop 均为 (0,0,4224,3136)。

离线将图像统一到1056×784（仅用于比较，不代表原图比例），以4224×3136为参考，SIFT匹配、0.7比例筛选、2像素RANSAC单应性配准。图像边界映射位置为特征拟合外推，不能排除亚像素或极小边界差异。场景以平面屏幕和周边背景为主，未做精密光学角度测量。每档约3秒的采集数量不是稳态帧率基准。

## 位姿内参影响
若确认使用同一完整画幅的纯缩放，尺寸从(W0,H0)改为(W1,H1)时：fx,cx分别乘W1/W0；fy,cy分别乘H1/H0；标准畸变参数保持不变（像素中心约定可能有亚像素偏移）。当前参考JSON标定分辨率仍未确认，本次视场测试不能证明其标定准确；现有节点会拒绝尺寸不匹配的CameraInfo。
